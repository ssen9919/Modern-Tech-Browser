# NEXUS – Modern Tech Browser 🚀

A futuristic cyberpunk-inspired web browser interface built using HTML, CSS, and JavaScript.

## Features

- Modern futuristic dashboard
- Google, Bing and DuckDuckGo search engines
- Smart URL and search navigation
- Voice search using Web Speech API
- YouTube, ChatGPT and Google Maps quick commands
- Quick website shortcuts
- Cyan, Purple and Green themes
- Live digital clock
- Matrix rain animation
- Website viewing through iframe
- Home and Refresh controls

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome 6.4
- Google Fonts
- Web Speech API
- HTML Canvas API

## Project Structure

NEXUS-Modern-Tech-Browser/
- Demo.html

- README.md

## Installation

1. Download the project.
2. Open it in Visual Studio Code.
3. Keep all three source files in the same folder.
4. Rename style(5).css to style.css.
5. Rename script(6).js to script.js.
6. Open Demo.html in your browser.

## Run Using Live Server

1. Install Live Server in VS Code.
2. Open Demo.html.
3. Right-click and select Open with Live Server.

## Quick Commands

| Command | Function |
|---|---|
| /yt music | Search YouTube |
| /ai | Open ChatGPT |
| /map | Open Google Maps |

## Limitations

- Some websites block iframe embedding.
- Voice search requires browser support and microphone permission.
- Internet is required for online services.
- This is a browser-style web application, not an independent browser engine.
- Multi-tab browsing, bookmarks, history and downloads are not yet implemented.
